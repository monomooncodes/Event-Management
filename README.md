# Event-Management
This is event management tickets booking system to  book and buy tickets. 

terminal codes.

1. Install env  -   env -m venv env
2. activate env -   env\Scripts\activate
3. install pip  -   pip install django
4. make project -   django-admin startproject project . 
5. make project (app) - python manage.py startapp student
6. run Django with -  python manage.py runserver
7. make migration - python manage.py makemigrations
8. make migrate - python manage.py migrate 
9. make superuser - python manage.py createsuperuser
